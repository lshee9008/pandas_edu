# 쉼자리 — 말로 묻고 지도가 답하는 쉼터 입지 결정 AI

**2026 주소정보 활용 대국민 공모전 응모작** (「쉼길」과 별개 출품 / 공통 데이터·분석 자산 공유)

> 지금까지 입지 결정은 "어디에 지을까"를 물었다.
> 쉼자리는 **"3억을 쓰면 갈 수 없던 몇 세대가 갈 수 있게 되는가"** 에 답한다.

---

## 무엇이 다른가 — 세 줄

| | 기존 | 쉼자리 |
|---|---|---|
| 수요 | 행정동 인구 | **호(戶) 단위** — 상세주소DB의 `지하 101호`·`옥탑` |
| 도달 | 직선거리 500m | **HWD** — 그늘·경사 가중 도보시간 (시각별) |
| 후보지 | 신축 부지 | **건물DB 기반 전환가능 유휴 공공건물** |

## AI 엔진 여섯 개

| | 엔진 | 하는 일 |
|---|---|---|
| ① | **SHADE-NET** | 건물 층수 + 태양 궤적 → 시각별 그늘 도로망. 오전 10시와 오후 2시의 도달권이 다르게 그려진다 |
| ② | **HOUSEHOLD-RISK** | 상세주소로 미등록 취약세대 발굴. MVP는 규칙 기반, 정식은 PU 러닝 |
| ③ | **NL2OPT** ★ | **한국어 정책 문장 → 최적화 수식 컴파일.** LLM은 문제만 만들고 해는 솔버가 낸다 |
| ④ | **TWIN** | 지도 클릭 → 반사실 즉시 재계산 + 한계효용 체감점 자동 탐지 |
| ⑤ | **PARETO** | 효율안 / 형평안을 나란히. AI가 정답을 정하지 않고 선택지를 준다 |
| ⑥ | **BRIEF** | 선정 근거 분해 + 보고서 초안 자동 생성 |

**간판은 ③이다.** 기존 GIS 입지분석은 기능이 없어서가 아니라 **쓸 사람이 부서에 없어서** 안 쓰인다. 쉼자리는 그 벽을 없앤다.

### AI 책임 분리 원칙

> LLM은 **해(解)를 만들지 않는다. 문제(問題)만 만든다.**

`정책 문장 → [LLM] → 최적화 스펙 → [담당자 승인] → [OR-Tools 솔버] → 해 → [LLM] → 설명`

환각이 예산 결정에 개입할 경로가 구조적으로 차단된다. 승인·솔버버전·해가 전부 append-only 로그로 남아 감사와 의회 답변에 그대로 쓸 수 있다.

## MVP 한 장 요약

**대상지 서울 관악구** (반지하 밀집 + 급경사 + 1인가구 최다 → HWD와 상세주소 효과가 가장 선명)

> "관악구 지하·옥탑 거주 N세대 중, 폭염 시 실제로는 도보 10분 내 쉼터에 갈 수 없는 M세대.
> 그리고 3억을 쓰면 그중 K세대가 갈 수 있게 되는 4개 건물."

직선거리로는 커버된다고 나오지만 HWD로는 아닌 곳. **이 지도 한 장이 제안 전체를 증명한다.**

## 스택

Python 3.11 · GeoPandas / Shapely · NetworkX · pvlib · **OR-Tools CP-SAT** · scikit-learn · **Claude API (claude-opus-5)** · Streamlit

폐쇄망 환경에서는 LLM 없이 폼 입력으로 전 기능이 동작한다. **AI는 편의 계층이지 필수 의존이 아니다.**
