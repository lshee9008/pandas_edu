과제 1

NumPy로 손글씨 들여다보기

★☆☆
데이터
from sklearn.datasets import load_digits — 1797장의 8×8 손글씨 숫자
목표
배열의 모양·축·브로드캐스팅·불리언 마스킹을 손에 익힌다
왜 이것
64개 숫자가 실제로는 그림이라, 축 연산이 무슨 뜻인지 눈으로 확인된다
  1. 배열의 정체 파악하기
    data의 shape, ndim, dtype, size를 출력하고 각각이 무슨 뜻인지 주석으로 적으세요. 값의 최소·최대도 확인합니다.
  2. 1차원을 2차원으로
    첫 번째 샘플(data[0], 길이 64)을 8×8로 reshape해서 plt.imshow(..., cmap='gray')로 그려보세요. 숫자 0의 모양이 보이면 성공입니다.
    • 이어서 앞 10장을 subplot으로 한 줄에 늘어놓아 보세요.
  3. 축(axis)의 의미
    data.mean(axis=0)과 data.mean(axis=1)의 shape가 왜 다른지 설명하세요.
    • axis=0 결과를 8×8로 reshape해서 그리면 "모든 숫자의 평균 이미지"가 나옵니다.
    • 가장자리 픽셀의 평균이 0에 가까운 이유도 생각해 보세요.
  4. 브로드캐스팅으로 정규화
    픽셀값 0~16을 0~1로 바꾸세요. 반복문 없이 한 줄이어야 합니다.
    • 이어서 열(픽셀)마다 평균 0·표준편차 1이 되도록 표준화해 보세요. 표준편차가 0인 픽셀에서 무슨 일이 생기는지 확인하고 대처하세요.
  5. 불리언 마스킹
    숫자 3인 샘플만 골라 개수를 세고, 그 평균 이미지를 그리세요.
    • 3 또는 8인 샘플만 고르려면? (np.isin 또는 |)
  6. 반복문 vs 벡터화
    모든 샘플의 픽셀 합을 ① for문 ② data.sum(axis=1) 두 방식으로 구하고 %timeit으로 속도를 비교하세요. 몇 배 차이가 나는지 적어두세요.
  7. NumPy → 판다스
    data를 DataFrame으로 만들고 target을 열로 붙인 뒤, 숫자별 픽셀 평균을 groupby로 구하세요. 결과 shape가 (10, 64)면 맞습니다.
검증
data.shape(1797, 64)
값 범위0.0 ~ 16.0
data.mean(axis=0).shape(64,)
data.mean(axis=1).shape(1797,)
숫자 3인 샘플 수183
클래스별 개수 범위174 ~ 183
groupby 결과 shape(10, 64)
과제 2

28년치 출생 데이터로 시계열 다루기

★★☆
데이터
source/시군구_성_월별_출생_20260730172059.csv
목표
2단 헤더 정리 → wide를 long으로 → 날짜 인덱스 → 리샘플링·이동평균
왜 이것
KOSIS 데이터의 전형적인 형태다. 이걸 다룰 줄 알면 통계청 자료 대부분을 쓸 수 있다
  1. 2단 헤더 다루기
    이 파일은 헤더가 두 줄입니다. 첫 줄은 기간(1997.01), 둘째 줄은 항목(계 (명)). pd.read_csv(..., header=[0,1])로 읽고 컬럼을 한 줄로 평탄화하세요.
    • '전국' 행은 시도 합계이므로 제외합니다.
  2. wide → long 변환
    월별 '계' 열만 골라 melt로 세로 형태로 바꾸세요. 결과는 시도 · 연월 · 출생아수 세 열이어야 합니다.
    • 연간 합계 열(1997 같은 것)이 섞이지 않게 주의하세요. 월별 열은 .이 있습니다.
  3. 날짜 타입으로
    '1997.01' 문자열을 pd.to_datetime(..., format='%Y.%m')으로 바꾸고 인덱스로 설정하세요. dt.year, dt.month, dt.quarter도 뽑아보세요.
  4. 리샘플링
    전국 월별 합계를 만든 뒤 resample로 연간·분기 합계를 구하세요.
    • 연도별 출생아 수 추이를 꺾은선으로 그리면 감소 추세가 한눈에 보입니다.
  5. 이동평균으로 계절성 걷어내기
    월별 데이터에 rolling(12).mean()을 적용해 원본과 겹쳐 그리세요.
    • 왜 12개월인지, 앞의 11개월이 NaN인 이유를 설명하세요.
  6. 계절성 확인
    월(1~12)별 평균 출생아 수를 구해 어느 달에 아이가 가장 많이 태어나는지 확인하세요.
  7. 시도별 비교
    2015년 대비 2024년 출생아 수 감소율을 시도별로 구해 정렬하세요. 가장 많이 줄어든 곳과 가장 덜 줄어든 곳은 어디인가요?
  8. 성비
    '남자'와 '여자' 열도 long으로 만들어 연도별 출생성비(여아 100명당 남아)를 계산하세요.
    • 1997년과 2024년을 비교하면 사회 변화가 숫자로 드러납니다.
검증
시도 수 (전국 제외)17
개월 수336 (1997.01 ~ 2024.12)
long 변환 후 행 수5,712 (= 17 × 336)
2022년 전국 합계249,186
2023년 전국 합계230,028
2024년 전국 합계238,317
한 걸음 더

2023년이 최저점이고 2024년에 반등했습니다. 왜 그런지를 데이터로 확인해 보세요 — 모든 시도에서 늘었는지, 특정 지역만 늘었는지. 월별로 보면 언제부터 돌아섰는지도 보입니다.

과제 3

281MB 파일을 다루는 법

★★☆
데이터
source/소상공인시장진흥공단_상가(상권)정보_서울_202503.csv — 540,516행 × 39열
목표
메모리를 의식하며 읽고, 나눠서 처리하고, 그룹으로 집계한다
왜 이것
지금까지는 read_csv로 통째로 읽었다. 실무에서는 그러다 메모리가 터진다
  1. 얼마나 큰지 재기
    먼저 nrows=5로 열 이름만 확인하세요. 39개 열 중 실제로 필요한 것을 골라 목록으로 만듭니다.
    • 파일 크기와 실제 메모리 사용량은 다릅니다. df.memory_usage(deep=True).sum()으로 확인하세요.
  2. usecols로 줄이기
    필요한 7개 열만 읽고, 전체를 읽었을 때와 메모리·시간을 비교하세요.
    • 추천 열: 상호명, 상권업종대분류명, 상권업종중분류명, 시군구명, 행정동명, 경도, 위도
  3. dtype 최적화
    반복이 많은 문자열 열을 category로, 좌표를 float32로 바꾸고 메모리가 얼마나 줄었는지 재세요. 70% 이상 줄어야 합니다.
    • pd.to_numeric(..., downcast='float')
  4. chunksize로 나눠 읽기
    chunksize=100000으로 나눠 읽으면서 시군구별 점포 수를 누적 집계하세요. 한 번에 다 읽었을 때와 결과가 같아야 합니다.
    • 각 조각의 value_counts()를 더해 나가면 됩니다.
  5. 그룹 집계
    시군구별 × 업종대분류별 점포 수를 pivot_table로 만드세요.
    • 강남구에서 가장 많은 업종은? 모든 구에서 그런가요?
  6. 업종 다양성 지표 만들기
    행정동마다 업종 중분류가 몇 종류나 있는지(nunique) 세어, 다양성이 높은 동 상위 10곳을 뽑으세요.
    • 점포 수가 많은 동과 다양성이 높은 동이 같은가요? 다르다면 왜일까요?
  7. 좌표 검증
    경도·위도가 서울 범위를 벗어난 행이 있는지 확인하세요. (대략 위도 37.4~37.7, 경도 126.7~127.2)
    • 이상치가 있다면 어떤 업종·지역인지 살펴보세요. 데이터 오류일 수도, 실제일 수도 있습니다.
검증
전체 행 수540,516
7개 열만 읽었을 때 메모리약 242 MB
category + float32 적용 후약 55 MB (77% 절감)
시군구 수 / 행정동 수25 / 425
업종 대분류 / 중분류10종 / 75종
점포 수 1위 자치구강남구 64,716
주의

low_memory=False 없이 읽으면 DtypeWarning이 뜹니다. 판다스가 파일을 조각내어 읽으면서 조각마다 다른 타입으로 추측했다는 뜻입니다. 경고를 끄는 대신 dtype=으로 직접 지정하는 습관을 들이세요.

과제 4

척도가 다른 데이터의 통계

★★☆
데이터
from sklearn.datasets import load_wine — 178개 와인 × 13개 성분, 3개 품종
목표
표준화가 왜 필요한지 체감하고, 결측치 처리 방법별 결과 차이를 비교한다
왜 이것
13개 특성의 단위와 자릿수가 제각각이다. 그냥 비교하면 큰 숫자가 결과를 지배한다
  1. 척도 차이 확인
    describe()로 13개 특성의 평균과 표준편차를 보세요. 가장 큰 값과 가장 작은 값의 자릿수 차이가 몇 배인지 계산합니다.
  2. 표준화 전후 비교
    원본과 표준화(z-score) 데이터로 각각 상자그림을 그려 나란히 놓으세요. 원본에서는 특성 하나가 그래프를 지배하는 모습이 보일 겁니다.
    • 공식은 직접 구현하세요 — (x - x.mean()) / x.std()
  3. 품종별 특성 비교
    target으로 groupby해서 품종별 평균을 구하고, 어떤 성분이 품종을 가장 잘 구분하는지 찾으세요.
    • 힌트: 그룹 간 차이가 크고 그룹 안 흩어짐이 작은 특성.
  4. 상관관계
    13개 특성의 상관행렬을 구해 히트맵으로 그리세요. 상관계수 절댓값 0.5 이상인 쌍만 뽑아 표로 정리합니다.
    • pearson과 spearman 결과가 다른 쌍이 있나요? 있다면 그 관계는 왜 다를까요?
  5. 결측치 만들어서 처리해 보기
    이 데이터엔 결측치가 없습니다. 직접 만드세요 — 무작위로 10%를 NaN으로 바꿉니다(random_state 고정).
    • 세 방법으로 채우기: ① 전체 평균 ② 품종별 평균 ③ KNNImputer
    • 각 방법의 결과를 원래 값과 비교해 오차(MAE)를 구하세요.
    • 어느 방법이 가장 정확한가요? 왜 그럴까요?
  6. 이상치 탐지
    IQR 방법으로 특성별 이상치 개수를 세세요.
    • 표준화 전후로 이상치 개수가 달라지나요? 달라지지 않는다면 그 이유는?
검증
데이터 shape(178, 13)
품종 수 / 각 개수3종 · 59 / 71 / 48
표준화 후 각 열 평균≈ 0 (1e-15 수준)
표준화 후 각 열 표준편차1.0
10% 결측 주입 시 NaN 개수약 231 (= 178 × 13 × 0.1)
이 과제의 핵심

5번에서 품종별 평균으로 채운 것이 전체 평균보다 정확할 가능성이 높습니다. 같은 그룹 안의 값들이 서로 비슷하기 때문입니다. "결측치는 평균으로 채운다"를 기계적으로 적용하지 말고, 데이터에 그룹 구조가 있는지 먼저 보라는 것이 이 과제의 교훈입니다.

반드시 포함할 것

  1. 질문 한 문장 — 노트북 맨 위에 적으세요. "데이터를 분석한다"가 아니라 "A는 B인가?" 형태여야 합니다.
  2. 데이터 출처와 기준 시점 — 어떤 파일을 썼고 언제 기준인지. 이번 세션에서 2018년 GeoJSON 때문에 겪은 일을 기억하세요.
  3. 전처리 기록 — 무엇을 버렸고 왜 버렸는지. 결측 몇 %를 어떻게 처리했는지 숫자로 적습니다.
  4. 두 개 이상의 데이터 결합 — merge 전후 행 수를 반드시 확인하고 기록하세요. 줄었다면 왜 줄었는지 설명합니다.
  5. 그래프 3개 이상 — 분포 1개, 비교 1개, 관계 1개. 모든 그래프에 제목과 축 이름을 답니다.
  6. 결론 5~10줄 — 숫자를 근거로. 예상과 달랐던 점을 반드시 포함하세요.
  7. 한계 3줄 — 이 분석으로 말할 수 없는 것을 적으세요. 유동인구를 반영하지 못했다든가, 폐업 점포가 포함됐다든가.
가장 흔한 함정

상관관계를 인과관계로 쓰는 것입니다. "학원이 많아서 출생아가 많다"가 아니라 "학원 밀도와 출생아 수는 양의 상관을 보인다"까지만 쓸 수 있습니다. 할리스 분석에서 "전북의 매장 밀도가 높다"는 사실이지만 "전북 사람들이 커피를 좋아해서"는 데이터로 뒷받침되지 않는 것과 같습니다.
