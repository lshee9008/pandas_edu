# 2026 주소정보 활용 대국민 공모전 — 정책 아이디어 분야

**제안명** — 쉼길: 주소로 계산하는 사계절 기후취약 대응 플랫폼 (부제: 격자에서 호(戶)까지)

> 쉼터는 이미 전국에 5만 개소가 넘는다. 쉼길은 *어디에 있나*가 아니라 ***여기서 갈 수 있나***를 주소로 계산한다.

## 공모 개요

| 항목 | 내용 |
|---|---|
| 주최 | 행정안전부 / 한국국토정보공사(LX) |
| 접수기간 | 2026. 7. 20. ~ 8. 31. |
| 제출처 | juso@lx.or.kr |
| 파일명 규칙 | `[정책]_응모작 제목_[참가자명/팀명]` |
| 참가자격 | 국민 누구나, 개인 또는 4인 이내 팀 |
| 심사 | 1차 서면심사(분야별 4편) → 2차 대국민투표 + 발표심사 |
| 시상 | 대상 200만원 / 최우수 100만원 / 우수 각 30만원 (행안부장관상·LX사장상) |
| 문의 | 주소정보활용지원센터 044-715-5513 |

원문 공지: https://www.juso.go.kr/ahh/ahhNoticeBoardDetail?ntcMttrMgno=224

## 구성 파일

| 파일 | 설명 |
|---|---|
| `정책제안서.md` | **제출용 본문.** 참가신청 서류(.hwp) 양식에 옮겨 붙이면 된다 |
| `서비스기획_쉼길.md` | 서비스 상세 설계 (12개 아이디어 통합 매핑 포함) |
| `분석_폭염한파_해상도.ipynb` | 첨부 분석자료. 제안의 전제를 실제 관측자료로 검증 (실행 결과 포함) |
| `그림1~3_*.png` | 제안서 삽입용 그래프 (노트북 출력에서 추출) |
| `collect_kma.py` | 기상자료개방포털 수집 스크립트 (API키 불필요) |
| `stations.json` | 전국 ASOS 105개 지점 ID·지점명·시도 매핑 |
| `kma_climate_days.csv` | 수집 결과 — 지점별 폭염·열대야·한파일수 (2016–2026) |

## 분석이 밝힌 것

| 발견 | 수치 |
|---|---|
| 시·도 내부 폭염일수 격차 (지점 3곳 이상 10개 시·도 평균) | **18.3일** |
| 최대 격차 — 경상북도 | **34.0일** (1.0 ~ 35.0) |
| 시·도로 묶어 줄어드는 편차 | **24%뿐** (전국 8.6일 → 내부 6.6일) |
| 폭염일수 ↔ 열대야일수 상관 | **-0.01 (무관)** |
| 폭염·한파 이중 노출 지점 | 86개 중 **23개 (27%)** |
| 최근 폭염 | 2024년 30.5일, 2025년 30.2일 (10년 중 최고) |

→ **행정구역은 위험의 단위가 아니다.** 더 촘촘한 공간 기준자가 필요하고, 그것이 주소다.

## 데이터 재수집

```bash
uv run python collect_kma.py
```

기상자료개방포털의 공개 CSV 다운로드 엔드포인트를 사용하므로 로그인·API키가 필요 없다.
전국 105개 종관기상관측(ASOS) 지점 × 3개 지표를 수집하며 약 15분 소요된다.

## 직접 받아야 하는 파일

공지사항 첨부파일은 사이트에서 직접 내려받아야 한다(스크립트 접근 불가).

- `1. 2026년 주소정보 활용 대국민 공모전 안내문.hwp` — 심사 배점 확인용
- `2. 공모전 참가신청 서류.hwp` — **제출 양식. 여기에 제안서 본문을 옮긴다**
- `3. 주소정보 데이터 다운로드 매뉴얼.pdf` — 상세주소DB 등 확보 경로
